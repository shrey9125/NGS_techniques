# Four-week learning path

Plan for 45–60 minutes per day. Keep notes in `LEARNING_LOG.md` and commit after each meaningful lesson.

## Week 1 — foundations and targeted DNA

- Day 1: FASTA, FASTQ, Phred quality, read length, depth, coverage.
- Day 2: platforms versus assays; short reads versus long reads.
- Day 3: library preparation, adapters, indexes, PCR duplicates, UMIs.
- Day 4: QC concepts: per-base quality, GC, duplication, contamination.
- Day 5: alignment, pileups, reference bias, variant allele fraction.
- Weekend: run Tutorial 1, inspect every output, answer its questions.

## Week 2 — genomes and communities

- Compare WGS, WES, panels, and amplicons.
- Learn SNVs, indels, CNVs, SVs, phasing, and annotation.
- Compare reference alignment with de novo assembly.
- Compare 16S/ITS profiling with shotgun metagenomics.
- Design a hypothetical study and justify assay, platform, depth, and controls.

## Week 3 — transcriptomes and regulation

- Compare poly(A), total RNA, small-RNA, and long-read RNA-seq.
- Learn counts, normalization, dispersion, multiple testing, and effect size.
- Compare ATAC-seq, ChIP-seq, CUT&Tag, methylation sequencing, and Hi-C.
- Sketch one workflow from biological sample to interpretable figure.

## Week 4 — single cell, reproducibility, and portfolio

- Learn barcodes, UMIs, count matrices, doublets, ambient RNA, and batch effects.
- Compare scRNA-seq, snRNA-seq, scATAC-seq, multiome, and spatial assays.
- Learn workflow managers, environments/containers, provenance, and data governance.
- Improve this repository: add one public-data tutorial, a figure, and a short reflection.

## Self-check questions

1. Can I state the biological question before naming a technology?
2. Can I distinguish biological replicates, technical replicates, and read depth?
3. Can I explain why high depth does not remove bias?
4. Can I choose between short and long reads and defend the choice?
5. Can another person reproduce my result from the repository and public inputs?

## Portfolio progression

1. Synthetic targeted-DNA tutorial (included).
2. Public bacterial isolate QC and assembly.
3. Small public bulk RNA-seq differential-expression analysis.
4. Optional specialization: single-cell, metagenomics, cancer genomics, or long reads.

Do not upload controlled-access or identifiable human data to GitHub.
